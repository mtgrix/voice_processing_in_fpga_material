\subsection*{V.3. Non-restoring narrative 22$\div$5}
Dividend 22, divisor 5, 6-bit. Quotient 4 remainder 2.
Liệt kê ý: mỗi bước shift AQ; nếu A$\\ge0$ trừ V set bit 1; else cộng V set bit 0 (non-restoring).
Sau 6 bước: chỉnh dấu dư nếu âm. Khớp $5\\cdot4+2=22$.
RTL TB phải in A,Q mỗi iter --- golden Python class \texttt{NonRestoringDiv}.
